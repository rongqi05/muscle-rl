# 阶段 C 简报：课程基线训练 v6（v1 热启动，6→8→10 s，预算 2e5）

## 设置（与 v1 语义一致）

* 权重热启动 `runs/train/healthy_v1`，**新经验池**（显式标注，非续训 buffer）；
* 课程 `s6(6.0s,min=0) → s8(8.0s,min=20000) → s10(10.0s,min=40000)`，
  晋级条件 = 验证成功率 ≥ 0.8；预算用完**不**无条件晋级；
* 奖励与 v1 完全一致：`w_survival=100`、`extra_reward` 四项目（lateral_dev 125.9 /
  lateral_vel 32.6 / forward_shortfall 42.0 / slip 3.26）、无侧向终止（null）；
* 每 2e4 transitions 验证（种子 101–105）+ 10 s 存活探针；每 5e4 周期检查点
  （模型+归一化+经验池+课程状态，可完整续训）；
* 预算：2e5 transitions / 300 分钟（原计划）。
